# Nebula

A Claude theme generated by [claude-image-theme](https://github.com/ddtam2604work/claude-theme-from-image) from the picture `nebula.png`: its palette colors the surfaces, text, borders and buttons, and the picture, redrawn as vector art under a readability veil, is the backdrop. It draws in the Claude desktop and mobile apps.

- `/image-theme-nebula` opens the settings pane: veil, glass, blur, picture detail, accent color, mode, stars, drift, bright borders.
- `/image-theme-nebula off` restores the default look, `/image-theme-nebula on` applies it again.
- Open `preview.svg` to see the backdrop.

Theme Claude được tạo bởi claude-image-theme từ ảnh `nebula.png`. Gõ `/image-theme-nebula` để mở bảng điều chỉnh (lớp phủ, kính mờ, độ nhòe, độ nét ảnh, màu nhấn, chế độ, sao, viền sáng); `/image-theme-nebula off` để tắt, `/image-theme-nebula on` để bật lại.
