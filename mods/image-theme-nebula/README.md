# Nebula

A Claude theme generated by [claude-image-theme](https://github.com/ddtam2604work/claude-theme-from-image) from the picture `nebula.png`: its palette colors the surfaces, text, borders and buttons, and a vector redraw of the picture under a readability veil is the backdrop. It draws in the Claude desktop and mobile apps.

- `/image-theme-nebula off` restores the default look, `/image-theme-nebula on` applies it again.
- Open `preview.svg` to see the backdrop.

Theme Claude được tạo bởi claude-image-theme từ ảnh `nebula.png`: bảng màu của ảnh tô nền, chữ, viền và nút; ảnh được vẽ lại bằng vector, có lớp phủ, làm hình nền. Gõ `/image-theme-nebula off` để tắt, `/image-theme-nebula on` để bật lại.
